# AI Solution Developer & AI Solution Architect — Learner Handbook

**Release 2026.11 · content as of October 2026 · Learner edition**

![Course map](assets/course-map.svg)

This handbook is the course text you work from. It takes a working software developer who is new to AI to assessed, expert-level practice as an **AI Solution Developer** or **AI Solution Architect**. The route is about 475 hours: a 274-hour shared core in three gated levels, one expert track of about 120 hours, and an 80-hour team capstone.

You learn by building. Throughout the course you grow one product, **Fleet Ops Copilot** for the fictional Plovdiv logistics company Trakia Freight. It starts as a single prompt and ends as a governed, multi-agent system running on Azure. Alongside the product you build **the Factory**: your own agentic software-delivery pipeline. From module C4 onward, all product work goes through coding agents that you specify, constrain and verify.

Every module uses the same sections: *Why this matters, Learning outcomes, Concepts, Tools & versions, Labs, Kata, Product increment, Factory increment, Assessment, Common pitfalls, References.* Start with [How to use this handbook](start-here/how-to-use.md).

## A note on currency

The platforms this course uses changed fast in 2026, and several features are still in preview. Product names, versions and preview/GA statuses are stated as of October 2026. Where a detail could not be confirmed from a primary source, the text says **"verify against current documentation"**. Treat those as prompts to check the current docs before you rely on them. Each module's *Tools & versions* table marks preview features, and every preview dependency has a GA fallback in the labs.
